# AntEvolve data

This repository has data used in AntEvolve training and evaluation.

## Credits

1.  The 30 networks were retrieved from: Tiago P. Peixoto, "The Netzschleuder network catalogue and repository", https://networks.skewed.de/ (2020), doi: https://doi.org/10.5281/zenodo.7839981
2.  The 550 networks were used in: Amir Ghasemian, Homa Hosseinmardi, Aram Galstyan, Edoardo M. Airoldi and Aaron Clauset
Stacking Models for Nearly Optimal Link Prediction in Complex Networks, PNAS USA 117(38), 23393-23400 (2020), doi: https://doi.org/10.1073/pnas.1914950117. Code and data available from https://github.com/Aghasemian/OptimalLinkPrediction
3. The synthetic networks are taken from: Alexey Vlaskin and Eduardo G Altmann 2025 J. Phys. Complex. 6 015004, doi: https://doi.org/10.1088/2632-072X/ada07f. Code available from https://github.com/avlaskin/synthetic-graphs-for-lp
4. The training data is a mix of sythetic networks (from point 3) and networks (from point 2).
